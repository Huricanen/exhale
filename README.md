# Exhale

Небольшое приложение для снятия стресса и бережной паузы в течение дня.
Проект помогает на несколько минут переключить внимание: замедлиться, сделать дыхательную практику и вернуться к текущим делам в более спокойном состоянии.

## Идея

Стресс не всегда можно устранить сразу, но короткая осознанная пауза может помочь снизить напряжение. Exhale создаётся как простое и ненавязчивое пространство для таких пауз — без перегруженного интерфейса и давления на пользователя.

## Планируемые возможности

- Дыхательные упражнения с понятным ритмом вдоха и выдоха.
- Короткие практики на 1–5 минут.
- Мягкие напоминания сделать паузу.
- Отслеживание настроения и самочувствия по желанию.
- Персональные рекомендации на основе выбранного состояния.

## Статус

Проект находится на ранней стадии разработки. Сейчас репозиторий содержит базовый Python-скелет приложения; функциональность практик ещё предстоит реализовать.

## Запуск

Требуется Python 3.13 или новее.

```bash
python main.py
```

Текущая команда запускает минимальную заготовку приложения.

## Важно

Exhale предназначен для повседневной самоподдержки и не заменяет помощь психолога, психотерапевта или врача. При сильной тревоге, длительном ухудшении самочувствия или риске причинить себе вред обратитесь за профессиональной помощью или в экстренные службы вашего региона.
